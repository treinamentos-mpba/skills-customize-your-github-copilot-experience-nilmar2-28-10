
# 📘 Assignment: Hangman Game

## 🎯 Objective

Construa um jogo da Forca em Python para praticar manipulação de strings, loops, condicionais, entrada de dados e seleção aleatória.

## 📝 Tasks

### 🛠️ Implement the Hangman Game

#### Descrição
Crie um jogo em que o programa seleciona uma palavra oculta e o jogador tenta adivinhá-la, informando uma letra por vez antes de esgotar as tentativas.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Aceitar palpites de uma letra e mostrar as letras descobertas e as posições ainda ocultas (por exemplo, `_ _ _`).
- Acompanhar e exibir o número de tentativas incorretas restantes.
- Encerrar quando o jogador adivinhar a palavra ou ficar sem tentativas.
- Exibir uma mensagem de vitória ou derrota ao final da partida.
